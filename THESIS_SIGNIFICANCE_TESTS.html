Thesis Significance Tests: Data Visualizations

1. Omnibus Friedman results (lollipop chart)

Length = -log10(Holm p across 20 outcomes). Dashed line = p = 0.05. Capped at 300 (p < 1e-300). Grey = not significant after Holm.

2. H1 agentic vs naive (forest plot)

Mean paired difference (agentic - naive) with unadjusted 95% CI, grouped by outcome. Right of zero favors agentic. Labels show Holm p over 720 tests.

3. Responses under 60 s (proportion with Wilson CI)

Dot = proportion, whisker = 95% Wilson CI, dashed line = 50% test threshold. Filled = Holm p < 0.05.

4. Latency omnibus (bar chart)

Friedman Q for the three latency metrics across six local configurations (all Holm p < 1e-136).

5. Latency pairwise (heatmap matrix)

Seconds, row minus column. Red = row faster (negative), blue = row slower (positive). * = Holm (45 tests) < 0.05.

6. Pairwise contrasts per outcome (heatmap matrix)

Cell = row minus column mean. Blue = row higher, red = column higher (scale per outcome). * = Holm within outcome < 0.05; ** = Holm across all 720 tests < 0.05. Hover for CI and p-values.
