Set up inline translation

    
French items can be translated into English, using
      DeepSeek through OpenRouter. You are asked for this once. If you already entered a key in the
      annotation tool on this computer it is reused here, and so are the translations you paid
      for.


    

      This is the one feature that sends data off this computer.
      Only the blocks of the item you press Translate on are sent, and only when you press it. That
      text is part of the collective agreement and of unpublished thesis results. Nothing else on
      this page ever leaves the machine, and no annotator judgement is ever sent.
